1. Feeding AAPS (integration)

Verbatim — AAPS docs / CompatibleCgms/Juggluco.md
For your G7 + AAPS setup, this is the key section.

Disable Nightscout uploader

Starting with AAPS 3.2, you shouldn't let any other app upload data (blood glucose and treatments) to Nightscout. Disable any active uploader to Nightscout in Juggluco.

Juggluco → AAPS (recommended)

Juggluco can send blood glucose directly to AAPS, enabling SMBs always if you are using a trusted sensor. When using a Libre 2/2+/3/3+ sensor, minute-by-minute readings will be sent to AAPS but will not trigger minute-by-minute calculations in AAPS.

Enable xDrip broadcast in Juggluco (do not enable Patched Libre), confirm and save the AAPS package information. Select the xDrip+ BG data source in AAPS. Apply sufficient smoothing in AAPS.

Your AAPS package name (full/patient build) is info.nightscout.androidaps. And remember the one-reader rule: only xDrip+ or Juggluco broadcasting into AAPS at a time — never both.

Juggluco → xDrip+ (alternative)

Juggluco can send blood glucose to xDrip+ which will then send them to AAPS. Enable Patched Libre in Juggluco (do not enable xDrip broadcast), confirm and save the dexdrip package information. Select the xDrip+ BG data source in AAPS. Apply sufficient smoothing in AAPS if necessary.

2. Glucose broadcasts (technical)

juggluco.nl/Juggluco/glucosebroadcast.html

Android applications can receive glucose values every minute from Juggluco. The broadcast sends the latest "Stream" glucose value each minute. For previous values, history, scans, or insulin/carb entries, use the web server in Juggluco.

Juggluco can imitate xDrip's broadcast (com.eveningoutpost.dexdrip.BgEstimate) or send a new broadcast: glucodata.Minute. The application id must be selected in Juggluco's left menu → Settings, either "xDrip broadcast" or "Glucodata broadcast".

Apps targeting Android 11+ only receive the broadcast when they add to their AndroidManifest:

<queries>
    <package android:name="tk.glucodata"/>
</queries>

Glucodata broadcast constants: ACTION glucodata.Minute; ALARM glucodata.Minute.Alarm; GLUCOSECUSTOM glucodata.Minute.glucose; MGDL glucodata.Minute.mgdl; RATE glucodata.Minute.Rate; SERIAL glucodata.Minute.SerialNumber; TIME glucodata.Minute.Time. Fields: name (from SERIAL), mgdl (int), glucose (float, in settings units), rate (float), alarm (int, bitwise — bit 3 = active alarm; bits 0–2 = level vs thresholds), time (long, ms). Rate label systems provided: xDrip, Dexcom, Libre (DoubleUp…DoubleDown).

3. Overview / how the app works

juggluco.nl/Jugglucohelp/introhelp.html

Juggluco scans Freestyle Libre sensors via NFC and receives values from Freestyle Libre 2/2+/3/3+, Sibionics GS1Sb and GS3, Dexcom G7/ONE+, Accu-Chek SmartGuide, CareSens Air, and Linx/Lumiflex/Aidex X sensors via Bluetooth.

Connect to Sibionics GS1Sb, Dexcom G7/ONE+, Accu-Chek SmartGuide, CareSens Air, or Linx/Lumiflex/Aidex X sensors by scanning their data matrix through left menu → Photo. Dexcom G7/ONE+ sensors pair via Bluetooth; confirm pairing promptly or wait five minutes. Keep the screen active during waiting. Samsung Galaxy Watch 4 and 7 bypass pairing confirmation. Expired Dexcom sensors remain reachable over Bluetooth. Prevent erroneous pairing by storing old sensors 15 meters away, and disable previously-connected apps and devices.

The four menus

Four menus open by touching empty display areas: left quarter → menu 1; left-center → menu 2; right-center → menu 3; right quarter → menu 4.

Menu 4 (right, Movement): navigate the curve; Date for date selection; Search to locate values; first item shows current time and jumps to "now." When "manually scale Glucose"/"manually scale Time" are enabled, screen movement / two-finger distance adjust the axes.

Menu 3 (right-center, Display): Last Scan; Scans; Stream; History; Amounts; Meals; Dark mode. "Stream" = one-minute Bluetooth glucose values (Libre 2/3). Scanning retrieves 15-minute history for the previous 8 hours.

Menu 2 (left-center): Export (.tsv); Mirror (IP/TCP to another Juggluco); New Amount; List; Statistics; Talk; Float (Floating Glucose overlay).

Menu 1 (left): System UI; Menus; Watch; Sensor; Settings; Photo; Close. Settings configures units (mmol/L or mg/dL), labels, alarms, reminders, display ranges. Sensor shows connection status. Photo scans a data matrix. Close exits.

4. Connecting sensors (incl. Dexcom G7)

juggluco.nl/Juggluco/sensors

In all cases you need to force stop the apps that previously connected with the sensor.

Dexcom G7 / ONE+

Scan the data matrix on the applicator with left menu → Photo. Keep the display on so you don't miss the opportunity to agree to pair the sensor. Extra notes (Juggluco wiki): put other used Dexcom sensors out of Bluetooth reach, and turn off apps/devices previously connected with the sensor (or turn off that device's Bluetooth). If you're too late to agree to pair, wait another 5 minutes. Dexcom G7/ONE+ disconnects after every glucose value (normal). To return to Dexcom's original app: terminate the sensor in Juggluco (left menu → Sensor → Terminate), then start the other app and enter its PIN. Dexcom ONE+ works exactly like G7. First Bluetooth reading can take 2–10 minutes.

Keep Juggluco alive in the background: allow background activity, turn off battery optimizations for Juggluco, and don't hide its notification (from the README). This is the same "Unrestricted / never sleeping" idea as your other apps.

Other sensors (reference)

  • Libre 2 / 2+: scan the sensor at least twice by holding the phone's NFC against it.
  • Libre 3 / 3+: Settings → Exchange data → Libreview; match account credentials; press "Get Account ID". Can only take over a sensor activated with Abbott's Libre 3 app (same account); cannot take over one started with a Libre 3 reader or the Unified/US Libre app. For Juggluco-only use, select "manual" and enter an arbitrary number.
  • Sibionics GS1: scan data matrix via Photo; specify type. GS3 (Juggluco 10.9.0+): one value per 5 min; bind to account ID.
  • Accu-Chek SmartGuide: scan the data matrix on the blue cap; enter the PIN also on the cap.
  • CareSens Air: scan the inner-package data matrix via Photo; only one device at a time.
  • Aidex X (10.7.0+) / LinX (10.7.2+): scan data matrix or Exchange data → Glucose Meters → Find devices.

5. Sensor screen & connection troubleshooting

juggluco.nl/Jugglucohelp/sensorhelp.html
  • Sensor selection: spinner shows active sensor; choose among multiple.
  • Doze Mode: battery-optimization link — prevent Juggluco being killed.
  • Bluetooth History: (Libre 2) receive 15-min history via Bluetooth; slower; no effect on Libre 3 / US-CA-AU-KR Libre 2.
  • Bug Workaround: Samsung Galaxy Watch 5+ needs it for Libre 3 correct 1-min intervals.
  • Alarm Clock (⏰): ensures proper Dexcom G7 / ONE+ connection timing, especially during deep sleep.
  • Permissions: Android 12+ needs "Nearby devices" permission for Bluetooth.
  • Device Address: shown after the identifier; red = US-variant sensor.
  • Forget: removes stored device address and rescans — sometimes needed to reconnect.
  • Terminate: stops Bluetooth connectivity to the sensor. Unpair: unbinds Linx/Lumiflex/Aidex X. Clear: wipes values from those sensors. Reset: Sibionics 2 only. Turbo: more connection effort, more battery. Android Connection: last-resort, slower. Info: start/end + last connection.

Troubleshooting

Successful Bluetooth connection needs: Bluetooth on; a successful scan; the sensor not connected to another reader/app; competing apps uninstalled/disabled/force-stopped. The Connection stage gives the most difficulty; status=133 ("Bluetooth device not found") is most common and usually resolves with patience. Fixes: restart Bluetooth, reboot the phone, disconnect interfering devices, rescan the sensor. Body positioning between sensor and watch can block signal. For persistent issues, in Android Settings → Connected Devices choose "Forget."

6. Settings

juggluco.nl/Jugglucohelp/settinghelp.html
  • Unit: mmol/L or mg/dL.
  • NFC sound: sound during scanning (plus vibration).
  • Scanning starts app: launches app on NFC scan even if not shown (Android may show a chooser).
  • Glucose notification (formerly "Glucose in android status bar"): shows streamed values quietly in the status bar; a dot appears if disabled. Background apps require a visible notification. On some phones values show only after disabling "Set to Silent" in that notification channel.
  • Floating glucose: small always-on-screen value; first use asks for display-over-other-apps permission.
  • Alarms: high/low, signal-loss, value-available.
  • Number labels: labels for insulin/carbs/activity.
  • Exchange data: transmit data to other apps/servers (web server, Libreview, glucose meters).
  • Reminders: remind to enter food/medication within time windows.
  • Google scan: use Google code scanner for data matrices/QR (else zXing).
  • Display: target range, language, display options.

7. Alarms, ringtone & advanced alarms

alarmhelp.html · ringtone.html · advancedAlarmshelp.html

Glucose alarms: Bluetooth-streamed values trigger low/high alarms. Low at/below a threshold; High at/above a threshold. Loss of signal if no data within a set time. Alarms stop when: duration expires, curve is touched, notification touched (unlocked), cancel pressed, or Floating Glucose touched. Value available: notified when a temporarily-stopped sensor works again. Category options: "Alarm" (alarm volume, audible when muted), "Notification" (silenced in DND), "Media" (media volume, routes to headphones). Default: which profile applies. Advanced: more alarm types/scheduling.

Ringtone

Minutes deactivated: a continuing low/high won't immediately re-alarm. Sound & Default: toggle audio / use system ringtone. Select: custom ringtone (some Samsung ringtone pickers crash — use an alternative). Vibrate. Disturb: if DND is on, turn it off before playing an alarm. Flash: flashlight for the alert's duration (useful where ringtones aren't allowed).

Advanced alarms

  • Very low glucose alarm — a second low alarm at a lower threshold.
  • Very high glucose alarm — a second high alarm at a higher threshold.
  • Alarm when soon below value — predicted fall below a value soon.
  • Alarm when soon above value — predicted rise above a value soon.
  • Schedules — activate a profile at a certain time of day (per-period thresholds/notifications).

8. New Amount, Labels & Meals

newamount.html · labelhelp.html · mealhelp.html

New Amount: enter numbers tied to a Label (configured in Settings → Number Labels); they display at set heights on the graph. Long-press an entry to edit; view via left-middle menu → List. Supports NovoPen 6 / Echo Plus dose import via NFC, Bluetooth finger-prick meters, a Meal button (build a meal from ingredients with auto carb calc), and an Exclude option to remove a BG reading from calibrations (e.g. during warmup or fast change).

Labels for amounts: create/delete/modify labels to specify insulin, carbohydrate, or physical activity. Renaming a position updates all historical entries at that position. Assign one label as "Meal" to get a Meal button in New Amount.

Meals: specify ingredient quantities; total carbohydrate is calculated (or specify total carbs and it computes the ingredient quantity). "Add item" to add ingredients; "Define" to create a new ingredient (name + carb content); "Database" opens a food-composition database to search foods and insert name/carbs.

9. Search

juggluco.nl/Jugglucohelp/searchhelp.html

Locate glucose readings and logged data. Search for values between given numbers (e.g. 10–999). Categories: Scan, History, History Calibrated, Stream, Stream Calibrated. Also find insulin/food/activity entries by selecting a label and a numeric range, with time-based filtering (e.g. lows in evening/early-morning hours). An arrow initiates the search direction; Reset restores parameters. Meal-ingredient search is possible when a label is designated as meals.

10. Statistics

juggluco.nl/Jugglucohelp/stathelp.html

Statistics from "AGP" with minor modifications; analyzed days set via Days. Data derive from the minute-by-minute Bluetooth values ("stream"). Left side shows time-in-range percentages (standard ranges always; a custom target range from Settings → Display shows below). % of time active = percentage of time Juggluco received values. Estimated A1C (Nathan 2008 formula). GMI (2018 formula; shown in Abbott's Libre 3 app). Glucose Variability = %CV = (SD/mean)×100%. Save generates a printable PDF report (needs web server enabled). Summary graph (≥9 days of stream data) shows glucose distribution across each minute of the day with median line and concentration shading.

11. Export

juggluco.nl/Jugglucohelp/helpexport.html

Meals are saved in HTML; all other data in .tsv (Tab-separated, UTF-8) — works with spreadsheets. Time Range (7.1.0+): choose how many days; end date = right edge of current view. Calibrated values: store processed and raw across data types; in Libreview format, calibrated values take priority. Libreview compatibility: convert to Libreview format (Dexcom/Sibionics/Libre have specific behaviors). Data can also be retrieved via the web server (Settings → Exchange data).

12. Mirror (device-to-device)

juggluco.nl/Jugglucohelp/connectionoverview.html

Mirror transmits data between devices (IP/TCP, or Bluetooth in 11.0.0+) so another Juggluco shows identical data. After receiving scan data, the mirror device can establish its own Bluetooth sensor connection; "Bluetooth use" auto-disables when IP/TCP data arrives (prevents multiple device-sensor contacts). Local Wi-Fi IP shows after "WLAN"; enter it on the connecting device; adjust the Port. "Add connection" specifies hosts/methods. Set Doze mode (battery optimizations disrupt network). Mirror sends amounts, Sync, Reinit, Auto QR, Wifi (WearOS). Usage abbreviations: n=amounts, s=scans, b=stream, r=receive. Also runs on desktop via Android emulator/Waydroid receiving data over Mirror.

13. Talk (speech)

juggluco.nl/Jugglucohelp/talkhelp.html

Speak glucose: speaks values as they arrive. Seconds between, Voice, Speed, Pitch, Test. Some phones need Android text-to-speech changes (on Samsung set "Google text-to-speech"). Talk touch: speaks on touching current glucose, graph/scan points, amounts, corner dates, long-pressed menu items/amounts. Speak messages reads temporary on-screen messages and scan results. Speak Alarms speaks the level at start and stop of Low/High alarms. Profile selects the active profile (Alarms + Talk settings are per-profile). Schedules activate a profile at a time of day. Volume: with MEDIA off, Notification slider controls it (silenced in DND); with MEDIA on, media volume (often audible in DND).

14. Watch / smartwatch

juggluco.nl/Jugglucohelp/watchinfo.html

Seven ways to show glucose on a watch: Notify (Android notification per value; "Separate" enables alarm notifications on some watches); Watchdrip (MiBand/Amazfit via Watchdrip+); GadgetBridge (glucose disguised as weather data); Kerfstok (watch app with activity + manual insulin entry); Broadcast (third-party apps like G-Watch relay to watches); xDrip Watch Apps (Juggluco's built-in xDrip/Nightscout webserver — fresher than traditional xDrip; Fitbit discontinued mid-2024); Wear OS Juggluco (dedicated Wear OS version + watch face over Bluetooth).

WearOS watch hardware compatibility (Juggluco wiki)

Watch must be WearOS (Android 8+); Juggluco can't use the watch's NFC — scanning is always done with the phone. Community notes: Samsung Galaxy Watch 4 works best with Juggluco (reliable when phone-connected or same-arm direct; ~24 h battery). Galaxy Watch 5–7/Ultra must reconnect every minute for minute-sending sensors (drains battery); fine with 5-minute sensors (Accu-Chek SmartGuide) — and G7 disconnects every reading anyway. OnePlus Watch 3 (larger 648 mAh) works very well, up to ~3 days phone-sensor (disable "Auto hibernation"); the 43mm version has half the battery. TicWatch Pro works like Watch 4 but turns Bluetooth off when very still (during sleep) — `adb shell dumpsys deviceidle disable` helps. Pixel Watch 3 reported good. Full list: juggluco.nl/JugglucoWearOS/watches.html. (You're not using a watch — included for completeness.)

15. Reminders

juggluco.nl/Jugglucohelp/reminders.html

Notifies when you fail to log a specified amount within a time window. Press NEW; set begin/end times for entering at least a given amount under a label. At the end time, if not recorded, a notification + audio alert fires. Example: "Levemir 6.0, 21:30–23:55" → reminded after 23:55 if fewer than 6 units of Levemir were logged after 21:30. Works after reboot without launching the app. Huawei: Settings → Battery → App launch → set Juggluco to "Manually managed" (Auto-Launch + Run in Background) — also needed for signal-loss alarms after reboot.

16. Floating glucose

juggluco.nl/Jugglucohelp/floatingconfig.html

Always-on-screen glucose value over other apps, with font size/color options. Touchable: reposition by dragging, shrink by long-press; when off, touches pass through to apps beneath (double-tap to disable touch). Transparent, Above (visible even when Juggluco is active), Time display, Active toggle. WearOS/Android Automotive need: adb shell pm grant tk.glucodata android.permission.SYSTEM_ALERT_WINDOW.

17. Libreview / Account ID (Libre only — not needed for G7)

libreview.html · getaccountidhelp.html

Get Account ID (for Libre 3 NFC scanning): "Manually" enter the ID, or "From Libreview" authenticate with email/password to receive it. You can send data to one Libreview account while Abbott's app uses another. Libreview settings: Send to Libreview (auto on app exit unless synced within 20 min; or "Send now"); Send Amounts; RU (libreview.ru, Libre 2 only); Immediate (real-time for LibreLinkUp); Spy Views; Change Start (restart transmission from a date). Not relevant to Dexcom G7.

18. Download & install

juggluco.nl/Juggluco/download.html

Runs on Android 5.0+ (Android 8 needed for Libre 3). Usual phone build: Arm64 APK from SourceForge (project: juggluco). Installing the APK updates the existing app. WearOS and "small" (Android Wear, Libre 2 only) builds exist. A logging build is available for bug reports.

For the kit: download the arm64 phone APK, archive it (self-signed, never expires). All versions are signed with the same key, so updates install over the top. Old versions: APKPure / SourceForge / the developer's Google Drive.

Downgrade: to install a lower version number, first install the "Downgrade version," then adb install -d -r releaseAPK. A "Second exemplar" (different Application ID) lets two Juggluco instances run on one phone for two people.
